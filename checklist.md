# GitHub Submission Checklist

- [ ] Repository name is `git-practice`
- [ ] Repository visibility is Public
- [ ] `README.md` is included
- [ ] `.gitignore` is included
- [ ] At least five files are tracked
- [ ] At least five commits are present
- [ ] Changes have been pushed to GitHub
- [ ] No passwords, access tokens, private keys, or other private information are committed
- [ ] The full repository URL is used as the submission title

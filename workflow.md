# A Simple Git Workflow

1. Make a small change to a file.
2. Run `git status` to inspect the change.
3. Stage the intended file with `git add <file>`.
4. Commit it with a descriptive message.
5. Review the history with `git log --oneline`.
6. Push your commits to the GitHub remote.

## Good commit messages
- `Add Git basics guide`
- `Document branch workflow`
- `Update submission checklist`

Keep each commit focused on one logical change.
Practice note: Check the working tree before committing changes.

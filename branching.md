# Branching Basics

A branch lets you work on a change separately from the main line of development.

## Create and switch to a branch
```bash
git switch -c practice-branch
```

## See available branches
```bash
git branch
```

## Return to the main branch
```bash
git switch main
```

## Merge a branch
```bash
git merge practice-branch
```

For a small practice repository, make sure your main branch contains the final files before submitting.
Practice note: Use branches to develop features separately.
